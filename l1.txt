>>  Advantages:

1.  Fast 
2.  Supports Microservices.
3.  Data Validation and Data fastening.  
4.  Easy to learn.
5.  Asynchronous Programming. (handles multiple requests)






HTTP Methods (CRUD):

        CLIENT          >>>>>>          SERVER

Get     --  To get some data from the server.
Post    --  To Add some data in the server.
Put     --  To Update some data in the server. 
Delete  --  To delete some data from the server.
Patch   --  To update a particular field from a data in the server.
